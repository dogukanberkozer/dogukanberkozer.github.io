Teen permit driving hours in Mississippi (2026): total, night, what counts

Short answer

  • Total: 50 hours of supervised driving
  • Night: no separate night requirement listed

Permy is an independent app, not affiliated with any state agency. Confirm the current requirements with your state agency before relying on them.

What counts as night in Mississippi

Night runs from sunset to sunrise. Permy works out sunset and sunrise from where you drive.

Your state's guidance doesn't give exact night hours, so Permy counts night from sunset to sunrise.

Pathways

This state has more than one set of requirements. Which one applies depends on the learner.

  • Under-17 road-test waiver: 50 total. Use this pathway if the applicant is under age 17. The under-17 50-hour pathway reflects the road-test waiver affidavit required by the current DPS Class R page; it is not a separate statutory night minimum. The affidavit is a required official document. Confirm current driver-education requirements as well.
  • Age 17 or older: Informational only. Permy does not apply the under-17 50-hour affidavit requirement universally to age 17 or older learners. The under-17 50-hour pathway reflects the road-test waiver affidavit required by the current DPS Class R page; it is not a separate statutory night minimum. The affidavit is a required official document. Confirm current driver-education requirements as well.

Sources

Under 17: the road-test waiver affidavit on the DPS Class R page asks for 50 supervised hours, and the signed affidavit is required. It doesn't set a separate night minimum. Age 17 or older: Mississippi sets no hour target, so Permy shows your hours without a goal. Driver-education changes planned for 2027 aren't included yet; check the current driver-education rules too.

Official sources:

  • Mississippi DPS Regular Class R License (current waiver applicability)
